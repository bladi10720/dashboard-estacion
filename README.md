# dashboard-estacion
Ventas de una estación de servicio.

## Carga de archivos (sin GitHub)
Este dashboard puede cargar datos de dos formas:

- **Carpeta local `datos/`**: coloca tus archivos `.xlsx` dentro de `datos/` y usa el botón **“Cargar desde `datos/`”**.
- **Carga manual**: usa el selector para subir uno o varios `.xlsx`.
